# 🎨 비주얼 자산 디자인 가이드라인 (Visual Asset Design Guide)

**적용 목표:** 출연자 얼굴 없이, 전문적이고 신뢰감 높은 '품격 컨설팅' 메시지를 전달하는 시각적 자산의 표준을 확립합니다. 모든 자산은 **'위기 통제감'**과 **'가족 품격'**을 시각적으로 구현하는 데 초점을 맞춥니다.

## 📊 2. 자산 유형별 디자인 브리프 (Asset Type Briefs)

### A. 데이터 시각화 (Infographics / Diagrams)
복잡한 개념(시간 흐름, 비용 비교, 리스크 분석)을 직관적으로 전달하는 데 사용합니다.

*   **[자산 1] 리스크 게이지 차트 (Risk Gradient Chart):**
    *   **기능:** 현재 대비 위험도를 시각적으로 보여줍니다.
    *   **디자인:** 딥 네이비 배경의 수평 막대 그래프. 위험도가 높을수록 뮤트 골드에서 Deep Navy로 점진적으로 어두워지는 그라데이션을 적용합니다.
    *   **활용 예:** "사후 대비(Low Risk)" vs "품격 관리(High Control)"를 비교할 때, 후자 쪽 게이지가 더 밝고 견고하게 채워지는 애니메이션을 사용합니다.
*   **[자산 2] 시간 흐름 플로우차트 (Timeline Flowchart):**
    *   **기능:** '사건의 발생 순서'나 '컨설팅 단계'를 시간 순으로 보여줍니다.
    *   **디자인:** 좌측에서 우측으로 흐르는 곡선 또는 점선 구조. 주요 마일스톤(Milestone)마다 뮤트 골드 원형 마커를 배치하고, 각 단계별 설명을 간결한 박스 형태로 연결합니다.
    *   **제한:** 텍스트는 최대 2줄로 제한하고, 아이콘(Iconography)을 필수적으로 병행합니다.
*   **[자산 3] 비교 체크리스트 (Comparative Checklist):**
    *   **기능:** '기존 방식'과 '제안 방식'의 차이점을 명확히 대비시킵니다.
    *   **디자인:** 2열 구조의 표. 좌측(❌)은 회색/딥 네이비 톤, 우측(✅)은 뮤트 골드 톤을 사용합니다. 체크 표시(✅)는 단순한 체크 마크가 아닌, 견고한 금속 질감의 심볼로 디자인합니다.

### B. 전문 애니메이션 (Motion Graphics)
텍스트와 개념을 역동적이고 전문적으로 표현하여 지루함을 방지합니다.

*   **[자산 4] 타이포그래피 계시 효과 (Typographic Reveal):**
    *   **기능:** 핵심 키워드나 문구가 화면에 등장할 때, 단순히 나타나는 것이 아니라 '쓰여지는' 듯한 모션을 부여합니다.
    *   **디자인:** 딥 네이비 배경 위에 뮤트 골드 폰트가 펜으로 필기하듯 나타나거나, 혹은 정교한 타이핑 효과를 거칩니다. (빠른 속도감과 정확성이 중요)
    *   **활용:** "가족의 품격"이라는 문구를 강조할 때 사용합니다.
*   **[자산 5] 추상적 연결 모션 (Abstract Connecting Motion):**
    *   **기능:** 여러 개념(A → B → C) 사이의 논리적 연결을 시각화합니다.
    *   **디자인:** 점선이나 레이저 빔처럼 보이는 선이 A 지점에서 시작하여, B 지점과 C 지점을 거치며 연결되는 모션을 사용합니다. (물리적인 연결을 통해 논리적 흐름을 강조)

### C. 고품질 스톡 푸티지 (Stock Footage / B-Roll)
얼굴 노출을 대체하며, '품격'과 '통제감'이라는 감성적 메시지를 전달하는 배경 영상을 정의합니다.

*   **[푸티지 1] 상징적 오브제 (Symbolic Objects):**
    *   **내용:** 클로즈업된 손(노년층 손, 단단한 손), 고급스러운 가구의 질감(나무 결, 대리석), 촛불, 나침반, 설계도.
    *   **촬영 기법:** 슬로우 모션(Slow Motion), 낮은 심도(Shallow Depth of Field)를 활용하여 피사체에 집중시키고, 영상 전체에 깊이감을 부여합니다.
