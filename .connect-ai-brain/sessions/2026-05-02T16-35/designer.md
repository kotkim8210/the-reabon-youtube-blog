## 🖼️ 썸네일 자동화 모듈형 디자인 시스템 설계 (3-Module System)

CEO의 지시에 따라, 딥 네이비/뮤트 골드 톤을 유지하며 주제별 변형이 용이한 **모듈형 썸네일 템플릿 시스템**을 설계했습니다. 이 시스템은 3가지 핵심 모듈(A, B, C)을 조합하여 콘텐츠의 단계별 목적(불안 자극 → 해결책 제시 → CTA)에 맞춰 자동화된 템플릿을 구축할 수 있습니다.

### 📐 디자인 시스템 스펙 요약

| 항목 | 규격 | 상세 내용 |
| :--- | :--- | :--- |
| **캔버스 크기** | 1280 x 720 px (16:9) | 유튜브 표준 썸네일 규격 |
| **주요 색상 (Primary)** | 딥 네이비 (#0F1A34) | 배경, 안정감, 전문성 담당 |

| **텍스트 색상** | 화이트 (#FFFFFF) / 라이트 그레이 (#E0E0E0) | 가독성 확보 |
| **폰트 패밀리** | **KoPub바탕/바른** (제목/헤드라인) + **Pretendard** (본문/설명) | 신뢰감을 주는 세리프와 모던함을 주는 산세리프 조합 |

### 🧩 3가지 핵심 모듈 정의 (Modular Components)

#### 🥇 Module A: 후킹/불안 자극 모듈 (ToFu - The Hook)
*   **목표:** 시청자의 잠재적 불안 요소를 자극하고, '무언가 빠져있다'는 인지적 공백을 만듭니다.
*   **레이아웃 원칙:** 대비(Contrast)와 질문(Question)을 통해 시선을 강탈합니다.
*   **배치 요소:**
    1.  **배경:** 딥 네이비 그라데이션 (좌측 30% → 우측 100%로 미묘한 변화).
    2.  **헤드라인 (H1):** 굵고 긴급한 느낌의 문구 배치. (폰트: KoPub바탕, 크기: 80pt, 색상: 화이트).
    3.  **후크 키워드 (K):** 가장 충격적인 키워드를 뮤트 골드로 배치하며, 좌측 상단에 **[!] 아이콘**과 함께 배치. (폰트: Pretendard, 크기: 60pt, 색상: 뮤트 골드).
    4.  **레이아웃 가이드:** H1은 텍스트를 3개 이상의 구로 분할하여 배치하고, 각 구 사이에 수직선을 넣어 전문적 긴장감을 부여합니다.
*   **예시 배치:**
    *   `[!]` (좌상단) → **"혹시, 이 부분은 준비하셨나요?"** (H1, 중앙)
    *   *배경:* 딥 네비 그라데이션

#### 🥈 Module B: 개념/해결책 제시 모듈 (MoFu - The Solution)
*   **목표:** 복잡한 문제를 체계적인 프로세스나 체크리스트로 단순화하여 '통제감'을 제공합니다.
*   **레이아웃 원칙:** 대칭성(Symmetry)과 구조화(Structuring)를 통해 신뢰도를 극대화합니다.
*   **배치 요소:**
    1.  **배경:** 전체적으로 밝은 무채색 톤(Deep Navy의 톤을 살린 그레이)을 사용하여 '보고서' 느낌을 강조.
    2.  **핵심 구조 (Grid):** 3~4개의 열(Column)로 나누고, 각 열마다 동일한 배경 박스(직사각형)를 적용합니다.
    3.  **제목 (H2):** 핵심 프로세스/단계명 배치. (폰트: Pretendard, 크기: 50pt, 색상: 딥 네비).
    4.  **설명/요소 (Bullet):** 체크리스트나 간결한 설명을 목록 형태로 배치. 각 목록 앞에 뮤트 골드 색상의 작은 원(•)을 배치하여 시각적 리듬을 만듭니다.
    5.  **레이아웃 가이드:** 정보의 흐름이 '문제점(좌) → 해결책(중) → 결과(우)' 순서로 자연스럽게 보이도록 배치합니다.
*   **예시 배치:**
    *   (좌) **[문제]** 딥 네비 박스 / (중) **[진단]** 골드 박스 / (우) **[결과]** 네비 박스
    *   *배경:* 전문적인 보고서처럼 보이는 무채색 배경

#### 🥉 Module C: 권위/CTA 모듈 (BoFu - The Authority)
*   **목표:** 최종적으로 브랜드의 권위와 다음 행동(CTA)을 명확하게 제시합니다.
*   **레이아웃 원칙:** 단순함(Simplicity)과 명확성(Clarity)에 집중하며, 브랜드 로고를 중심에 배치합니다.
