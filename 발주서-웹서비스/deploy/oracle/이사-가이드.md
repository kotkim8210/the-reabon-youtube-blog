# rj-balju → 오라클 클라우드 이사 (서버비 0원)

Fly.io 월 비용을 없애고, **지금 기능을 그대로** 24시간 돌리기 위한 절차.
오라클 "Always Free" 등급은 기간 제한 없이 무료다.

---

## 사용자가 직접 해야 하는 것 (계정 관련)

### 1. 오라클 클라우드 가입
1. https://www.oracle.com/kr/cloud/free/ → **무료로 시작하기**
2. 국가 **대한민국**, 홈 리전은 **춘천(Chuncheon)** 또는 **서울(Seoul)** 선택
   - ⚠️ 홈 리전은 나중에 못 바꾼다
3. 카드 등록 필요(본인 확인용). **Always Free 자원만 쓰면 청구되지 않는다.**
   가입 후 계정이 "유료 전환"되지 않도록 그대로 두면 된다.

### 2. 서버(인스턴스) 만들기
콘솔 → **Compute → Instances → Create instance**

| 항목 | 값 |
|---|---|
| 이미지 | **Ubuntu 24.04** (또는 22.04) |
| Shape | **VM.Standard.A1.Flex** — OCPU 2, 메모리 12GB |
| | (A1 용량 없다는 오류가 나면 **VM.Standard.E2.1.Micro**로 대체) |
| 네트워크 | 기본값(공인 IP 할당 체크) |
| SSH 키 | **Generate a key pair** → **개인키(.key) 다운로드 후 보관** |

> A1(ARM)이 "Out of capacity"면 리전을 춘천↔서울로 바꿔 다시 시도하거나,
> E2.1.Micro(1GB)로도 충분히 돌아간다. 지금 Fly 머신이 512MB다.

### 3. 방화벽 열기 (두 군데 다 해야 함)
1. 인스턴스 상세 → **Virtual cloud network → Security Lists → Default Security List**
   → **Add Ingress Rules** 2개 추가
   - Source `0.0.0.0/0`, IP Protocol `TCP`, Destination Port `80`
   - Source `0.0.0.0/0`, IP Protocol `TCP`, Destination Port `443`
2. 서버 안쪽 iptables는 접속 후 내가 처리한다.

### 4. 무료 도메인 (HTTPS용)
1. https://www.duckdns.org → 구글/깃허브 계정으로 로그인
2. 원하는 이름 입력 후 **add domain** (예: `rjbalju` → `rjbalju.duckdns.org`)
3. **current ip** 칸에 오라클 인스턴스의 **공인 IP**를 넣고 **update ip**

### 5. 나에게 알려줄 것
- 공인 IP 주소
- 다운로드한 SSH 개인키 파일 경로 (예: `C:\Users\USER\Downloads\ssh-key-2026-09-08.key`)
- DuckDNS 주소 (예: `rjbalju.duckdns.org`)

---

## 여기서부터는 내가 처리한다

6. 서버 접속 → Docker 설치, iptables 80/443 개방
7. 소스 복사 + `.env` 구성(시크릿 13개는 `export-from-fly.sh`로 Fly에서 그대로 이전)
8. 데이터베이스(발주 이력·규칙·설정) 이전
9. `docker compose up -d --build` → Caddy가 Let's Encrypt 인증서 자동 발급
10. 전체 기능 실측 (발주서·운송장·마진방어·이메일)
11. 문제 없으면 Fly 앱 2개 정지

---

## 이사 후 사용자가 한 번 더 해야 하는 것

- **쿠팡 WING → API 사용 IP 등록**을 새 서버 공인 IP로 변경
  (고구마 주문 자동수집·송장등록·CS가 이 IP에 묶여 있다.
   발주서/운송장 엑셀 기능은 IP와 무관해서 영향 없음)
- 즐겨찾기를 새 주소(`https://내주소.duckdns.org`)로 변경

---

## 옮겨도 그대로 유지되는 것

- 모든 발주서 생성·운송장 입력 (콜라비·명이·제이비티·비셀러·게걸무·고구마·참두릅)
- 마진방어 **매일 오전 10시 자동 감시** (스케줄러 그대로 동작)
- 중복발주 방지 이력, 상품 매칭 규칙, 도구 설정 (DB 통째로 이전)
- 쿠팡·토스 API 연동, 발주서 이메일 발송, 일요일 새벽 DB 백업
