## 빠른 시작

### 5분 안에 첫 발주서 생기게 하는 순서

1. **회원가입** (30초) → 구글/이메일로 가입  
2. **샘플 파일 다운로드** (1분) → 첫 발주서 형태 확인  
3. **상품 1개 등록** (2분) → "콜라비" 예시 1개 추가  
4. **DeliveryList 업로드** (1분 30초) → 발주서 자동 생성 확인  

**목표:** 가입 후 10분 내 첫 자동 발주서 생성 체험

## 회원가입 및 로그인

### 1단계: 웹사이트 접속

```
https://rj-balju.fly.dev
```

**화면에서 보이는 것:**
- 상단: 발주메이트 로고
- 중앙: "회원가입" 버튼
- 하단: "이미 계정이 있으신가요? 로그인" 링크

### 2단계: 회원가입 방법 선택

**A. 구글 계정으로 가입 (권장 - 가장 빠름)**

1. "구글 계정으로 가입" 버튼 클릭
2. 구글 로그인 창에서 이메일 입력
3. 비밀번호 입력 후 로그인
4. 자동으로 발주메이트 로그인 완료

**B. 이메일·비밀번호로 가입**

1. 아이디 입력 (3~32자, 영문·숫자·언더스코어)
   - 예: `user123`, `농사꾼_김철수`
2. 이메일 입력 (실제 받는 이메일)
3. 비밀번호 입력 (8자 이상)
   - 예: `MySecure@Pass123`
4. 비밀번호 확인 (같은 비밀번호 재입력)
5. "가입하기" 버튼 클릭

### 3단계: 가입 후 첫 화면

가입 직후 다음 페이지 중 하나로 자동 이동:
- **"/my/products"** → 상품·거래처 양식 설정 페이지
- **로그인 후에는 언제든** 좌측 메뉴에서 접근 가능

### 로그인 (이미 계정이 있는 경우)

1. https://rj-balju.fly.dev/login 접속
2. 이메일 + 비밀번호 입력 (또는 구글 계정 선택)
3. "로그인" 클릭
4. 자동으로 대시보드 이동

**브라우저가 자동으로 기억하나요?**  
네, 세션이 7일간 유지됩니다. 7일 후 다시 로그인 필요.

## 상품·거래처 양식 등록

### 개념: 왜 이 단계가 필요한가?

발주메이트의 핵심은 **"사용자마다 다른 상품명, 거래처 양식에 자동화를 맞춘다"**는 것입니다.

- **예1:** A 셀러는 콜라비를 "당일 콜라비(특)"로 쿠팡에 올림 → 거래처 B는 엑셀에 "콜라비/특품/5kg" 칸이 있음
- **예2:** B 셀러는 참외를 "성주참외 로얄과"로 올림 → 거래처 C는 엑셀에 "로얄과/12과" 칸이 있음

이 매칭을 미리 등록해야 DeliveryList만 올리면 발주서가 **자동으로 거래처 형식**으로 생성됩니다.

### 화면 접근

**좌측 메뉴** → "상품·양식 설정" (또는 `/my/products` URL)

### 등록 단계

#### 1단계: 상품 추가

**버튼 위치:** "상품 추가" 또는 "+" 아이콘

**입력 항목:**

| 항목 | 예시 | 설명 |
|------|------|------|
| 상품명 | 콜라비 | 쿠팡에 올린 그대로의 상품명 (정확히) |
| 카테고리 | 채소/과채 | 선택지: 콜라비, 참외, 토마토, 고구마, 명이나물, 땅두릅, 수박 등 |
| 기본 옵션 | 당일 콜라비(특) | 쿠팡 DeliveryList 옵션명 |

**예시 입력:**
- 상품명: `콜라비 (당일품)`
- 카테고리: `콜라비`
- 기본 옵션: `당일 콜라비(특)`

**저장:** "저장" 버튼 클릭

#### 2단계: 거래처 양식 등록

**버튼 위치:** 상품 등록 후 "거래처 양식" 탭

**입력 항목:**

| 항목 | 예시 | 설명 |
|------|------|------|
| 거래처명 | 산지직송 농장 | 엑셀 파일 이름이나 거래처 명칭 |
| 엑셀 파일 | `발주서_농장A.xlsx` | 거래처가 주는 엑셀 양식 파일 업로드 |
| 상품명 매칭 셀 | C2 | 어느 셀에 상품명을 넣을지 (예: 콜라비) |
| 옵션명 매칭 셀 | D2 | 어느 셀에 옵션명을 넣을지 (예: 당일 콜라비(특)) |
| 수량 매칭 셀 | E2 | 어느 셀에 수량을 넣을지 |

**엑셀 셀 찾는 법:**

1. 거래처 양식 엑셀을 엽니다
2. 예: 열 C에 상품명이 들어가는 부분 찾기
3. 첫 번째 행(제목 제외)이 C2라면 **C2** 입력

**예시:**
```
거래처: 산지직송 농장 A
양식 파일: farmer_a.xlsx

상품명 셀: C2
옵션명 셀: D2  
수량 셀: E2
```

**파일 업로드 팁:**
- 거래처 양식 엑셀을 그대로 업로드하면 됩니다 (수정 금지)
- 여러 거래처가 있으면 각각 따로 등록합니다

**저장:** "등록" 클릭

### 3단계: 확인 및 수정

**등록 후 화면:**

| 항목 | 위치 |
|------|------|
| 등록된 상품 목록 | 상단 "상품" 탭 |
| 등록된 거래처 목록 | "거래처 양식" 탭 |
| 수정 | 각 항목 옆 "수정" 버튼 |
| 삭제 | 각 항목 옆 "삭제" 버튼 |

## 기능별 가이드

### A. 발주서 생성하기 (DeliveryList 처리)

**목적:** 쿠팡 주문 엑셀(DeliveryList) → 거래처별 발주서 자동 생성

#### 단계별 진행

**1단계: 메뉴 접근**

좌측 메뉴 → "DeliveryList 처리" (또는 `/my/process` URL)

**2단계: DeliveryList 파일 준비**

```
쿠팡 로켓그로스 → 판매 → DeliveryList 다운로드
```

다운로드한 파일:
- 파일명: `delivery_list_YYYYMMDD.xlsx` (예: `delivery_list_20260603.xlsx`)
- 형식: Excel 파일
- 내용: K열=상품명, L열=옵션, M열=수량

**3단계: 파일 업로드**

1. "DeliveryList 업로드" 버튼 클릭 (또는 영역에 파일 드래그)
2. 파일 선택 후 "열기"
3. "업로드" 또는 "처리" 버튼 클릭

**4단계: 처리 완료 확인**

화면에 다음이 표시됩니다:
- 처리 상태: "완료" (녹색) 또는 "일부 실패" (황색)
- 성공 건수: `45/50건 성공`
- 거래처별 발주서 목록

**5단계: 발주서 다운로드**

**개별 다운로드:**
- 각 거래처 옆 "다운로드" 버튼 클릭
- 파일명: `발주서_거래처명_YYYYMMDD.xlsx`

**전체 다운로드 (ZIP):**
- 우측 상단 "전체 다운로드" 버튼 클릭
- 모든 발주서가 ZIP 파일로 묶여 다운로드

**6단계: 거래처에 전송**

다운로드한 발주서를 거래처에 메일/카톡으로 전달합니다.

---

### B. 운송장번호 입력하기 (다중 회신 처리)

**목적:** 거래처가 회신한 엑셀(운송장번호 포함) → 쿠팡 주문에 자동 매칭

#### 단계별 진행

**1단계: 메뉴 접근**

좌측 메뉴 → "일괄 운송장 입력" (또는 `/orders/batch-tracking` URL)

**2단계: 거래처 회신 파일 준비**

거래처로부터 받은 엑셀 파일들:

| 항목 | 설명 |
|------|------|
| 파일 개수 | 1개~여러 개 (모두 한 번에 업로드 가능) |
| 필수 칼럼 | 주문번호(또는 상품명), 운송장번호 |
| 파일명 예시 | `회신_농장A.xlsx`, `배송현황_농장B.xlsx` |

**주의:** 거래처 회신 파일에는 다음이 있어야 합니다:
- 원래 발주서의 주문번호 또는 상품/옵션/수량 조합
- 운송장번호 (새로 추가된 칼럼)

**3단계: 파일 업로드 (한 번에 여러 개)**

1. "파일 선택" 또는 드래그 앤 드롭 영역 클릭
2. 첫 번째 거래처 회신 파일 선택
3. **Ctrl (또는 Cmd) 누르고** 두 번째, 세 번째 파일도 선택
4. "열기" 클릭 (여러 파일 동시 선택됨)

**파일 여러 개 한 번에 올리는 팁:**
```
1. 거래처_A.xlsx 클릭
2. Ctrl + 클릭 → 거래처_B.xlsx
3. Ctrl + 클릭 → 거래처_C.xlsx
4. "열기" 버튼 클릭
```

**4단계: 매칭 확인 및 처리**

화면에 표시:
- 감지된 파일 개수: `3개 파일 업로드됨`
- 인식된 주문/운송장 쌍: `127개 매칭 발견`
- 매칭 실패 건 (있으면): `3건 매칭 실패 - 사유 보기`

**5단계: 매칭 검토 (필요시)**

매칭 실패가 있으면:
1. "실패 목록" 클릭
2. 원인 확인 (예: 주문번호 오타, 수량 불일치)
3. 거래처에 정정 요청 또는 수동 입력

**6단계: 최종 등록**

1. "등록" 또는 "확정" 버튼 클릭
2. 확인 메시지: "127건 운송장이 등록되었습니다"
3. 완료!

**결과 확인:**
- 등록된 운송장 목록 페이지 이동
- 각 주문번호별 운송장번호 확인 가능

### C. 쿠팡 운송장 자동 등록

**목적:** 등록된 운송장번호를 쿠팡에 자동으로 입력 (수동 업로드 스킵)

**전제 조건:**
- 쿠팡 로켓그로스 API 키 연동 필수 (아래 "쿠팡 API 키 연동" 참조)
- 운송장이 이미 입력되어 있어야 함 (위 B단계 완료)

#### 단계별 진행

**1단계: API 키 연동 확인**

좌측 메뉴 → "설정" → "쿠팡 API 키"

표시되는 상태:
- **초록색 체크:** API 키 연동됨 ✓
- **빨간색 X:** API 키 등록 필요 ✗

**쿠팡 API 키가 없으면:**
1. "키 등록하기" 버튼 클릭
2. 쿠팡 로켓그로스 관리자 → 개발자 센터 → API 인증 정보 확인
3. 발급된 키 2개 복사:
   - `Coupang API Key` (매장 ID)
   - `Coupang API Secret` (시크릿 키)
4. 발주메이트의 입력 칸에 각각 붙여넣기
5. "저장" 클릭

**2단계: 메뉴 접근**

좌측 메뉴 → "쿠팡 운송장 등록" (또는 `/orders/coupang-sync` URL)

**3단계: 등록 대상 확인**

화면에 표시:
- 아직 쿠팡에 등록되지 않은 운송장 목록
- 예: `15건의 주문이 운송장 대기 중`

**4단계: 일괄 등록**

1. "모두 등록" 또는 "등록" 버튼 클릭
2. 진행 상황 표시:
   - `등록 중... (5/15)`
   - `완료 (15/15) ✓`
3. 결과 요약:
   - 성공: `15건 쿠팡에 등록됨`
   - 실패 (있으면): `1건 실패 - 원인: API 오류 (재시도)`

**5단계: 쿠팡에서 확인**

쿠팡 로켓그로스 → 판매 → 주문관리  
→ 각 주문의 운송장번호 란이 자동으로 채워져 있음!

**주의사항:**
- 쿠팡 API는 **하루 10,000건 요청 제한**
- 대량(3,000건 이상)인 경우 시간을 나누어 등록
- 실패한 주문은 자동 재시도 (최대 3회)

### D. 마진방어 (공급가 모니터링)

**목적:** 거래처 공급가 변동을 한눈에 보고 역마진 방지

#### 단계별 진행

**1단계: 메뉴 접근**

좌측 메뉴 → "마진방어" (또는 `/my/dashboard` URL에서 "마진방어" 섹션)

**2단계: 공급가 모니터 확인**

화면에 표시:

| 항목 | 의미 |
|------|------|
| 콜라비 | 거래처 공급가 추이 그래프 |
| 색상 (파란색) | 공급가 ↑ (주의!) |
| 색상 (회색) | 공급가 ↓ (좋음) |
| 색상 (같음) | 공급가 변동 없음 |
| 마지막 확인 | "1시간 전", "어제 오전 9시" |

**모니터 항목:**
- 콜라비, 참외 (성주/알뜰/로얄), 토마토, 고구마, 명이나물, 땅두릅, 수박 등

**3단계: 가격 변동 상세 보기**

클릭: 각 상품 카드

표시되는 정보:
```
콜라비
이전 공급가: ₩3,500/kg
현재 공급가: ₩3,800/kg
변동: +₩300 ↑ (위험 신호!)

마지막 확인: 2026-06-03 오전 10:30
거래처: 산지직송 농장
```

**4단계: 소싱현황 다운로드 (마진 계산용)**

1. "소싱현황 다운로드" 버튼 클릭
2. 파일 내용:
   - 전체 거래처 공급가 목록
   - 쿠팡 현재 판매가
   - 자동 계산된 마진율 (%)
3. 역마진 상품 확인:
   - 마진율이 음수(-) → 손해
   - 마진율이 0~10% → 주의

**5단계: 가격 조정 결정**

마진율이 낮으면:
- **옵션 1:** 쿠팡에서 판매가 올리기
- **옵션 2:** 거래처 변경 (다른 농장에서 더 저렴한 가격으로)
- **옵션 3:** 상품 중단

**팁:**
- 매주 1회 이상 확인 추천
- 마진율이 -5% 이하이면 긴급 조치 필요

필터 영역:

**5단계: 보고서 내보내기**

1. "내보내기" 또는 "다운로드" 버튼 클릭

## FAQ

### 가입 및 로그인

**Q1. 비밀번호를 잊었어요.**

A. 로그인 페이지 → "비밀번호 찾기" 클릭 → 이메일 입력 → 재설정 링크 메일 수신 → 새 비밀번호 설정

**Q2. 여러 계정을 만들 수 있나요?**

A. 네, 이메일마다 1개 계정. 그러나 권장하지 않습니다. 1명 셀러 = 1계정 원칙. (여러 거래처는 1계정 안에 등록)

**Q3. 구글 계정으로 가입했는데 비밀번호를 설정할 수 있나요?**

A. 나중에 설정 가능. 좌측 메뉴 → "계정 설정" → "비밀번호 설정" 클릭.

### 상품·양식 등록

**Q4. 거래처가 여러 개면 각각 양식을 등록해야 하나요?**

A. 네. 거래처마다 엑셀 양식이 다르면 각각 등록. (예: 농장A, 농장B 각각)

**Q5. 상품명이 쿠팡에서 자주 바뀌어요. 매번 등록을 다시 해야 하나요?**

A. 아니요. "상품 수정" → 상품명만 변경하면 됨. 거래처 양식 다시 등록 불필요.

**Q6. 거래처 양식 파일의 어느 셀에 들어가는지 모르겠어요.**

A. 거래처 엑셀 파일을 열어서:
1. "상품명"이 들어가는 첫 셀 찾기 (예: C2)
2. 그 셀의 좌표(C2)를 "상품명 매칭 셀"에 입력

더 어려우면 거래처에 "어느 셀에 상품명을 넣으면 되나요?" 물어보기.

### 발주서 처리

**Q7. DeliveryList가 비어 있어요.**

A. 확인 사항:
1. 쿠팡 로켓그로스 → 판매 → 주문관리 에서 최근 주문 있는지 확인
2. DeliveryList는 **매일 정해진 시간(보통 오전 8시)에 생성**
3. 아직 주문이 없으면 샘플 파일 다운로드해서 테스트

**Q8. 발주서가 비어 있어요 (파일은 있는데).**

A. 체크리스트:
1. 상품이 등록되어 있나? (상품·양식 설정에서 확인)
2. 상품명이 DeliveryList의 **K열 상품명과 정확히 일치**하나? (띄어쓰기, 괄호도 같아야 함)
3. 거래처 양식이 등록되어 있나?

예: DeliveryList에 "콜라비 (당일품)" → 등록된 상품명도 정확히 "콜라비 (당일품)" 이어야 함.

**Q9. 발주서가 여러 거래처로 쪼개져요. 이건 맞나요?**

A. 네, 정상입니다. 각 거래처가 다른 양식이므로 자동으로 분리됨.
- 예: 콜라비는 농장A, 참외는 농장B → 2개 발주서 생성

### 운송장 입력

**Q10. 운송장이 매칭되지 않아요.**

A. 가능한 원인:
1. **주문번호 오타** → 거래처에 확인해서 정정
2. **상품명이 다름** → 발주서와 회신 파일의 상품명이 다르면 수동 입력 필요
3. **수량 불일치** → 발주한 수량과 회신한 수량이 다름 → 확인 후 수정

**Q11. 여러 거래처 회신을 한 번에 올릴 수 있나요?**

A. 네! Ctrl(또는 Cmd) + 클릭으로 여러 파일 동시 선택 후 올리면 됨.

### 쿠팡 API

**Q12. 쿠팡 API 키는 어디서 얻나요?**

A. 쿠팡 로켓그로스 관리자 → 개발자 센터 (또는 "API 관리") → 인증 정보에서 확인:
- "API Key" (또는 "Shop No" / "Seller ID")
- "API Secret" (또는 "Access Key")

**Q13. API 키를 넣었는데 "연동 실패"가 뜨네요.**

A. 확인 사항:
1. 복사할 때 **앞뒤 공백** 제거
2. 키가 정확한지 쿠팡 개발자 센터에서 다시 확인
3. 쿠팡 API가 활성화되어 있는지 확인 (상점 설정)

### 마진방어

**Q14. 마진율이 음수인데 뭘 해야 하나요?**

A. 역마진 상태. 3가지 방법:
1. **판매가 올리기:** 쿠팡에서 가격 인상
2. **거래처 변경:** 더 싼 농장 찾기
3. **상품 중단:** 해당 상품 판매 중단

**Q15. 공급가는 언제 업데이트되나요?**

A. 매일 정해진 시간(보통 오전 6시)에 자동 업데이트. "마지막 확인" 시간 확인.

### 요금 및 결제

**Q16. Free에서 Pro로 업그레이드하면 사용하던 데이터는?**

A. 모두 유지됨. 기존 상품, 발주서, 거래처 모두 그대로 사용 가능.

**Q17. Pro 구독을 취소하면 데이터가 지워지나요?**

A. 아니요. 데이터는 모두 보관됨. 다시 Pro를 신청하면 그대로 복구됨.

**Q18. 월 3,000건을 초과하면?**

A. 초과분은 자동으로 발주서 생성이 차단됨. 그 전에 알림이 뜸.
- 해결책: Pro 플랜 유지 또는 다음 달 대기

### 기술 및 트러블

**Q19. 파일을 여러 번 올렸는데 중복 처리된 것 같아요.**

A. 확인 방법:
1. 발주서 다운로드 후 파일 확인
2. 같은 주문번호가 2번 이상 있나 체크

중복이 있으면 거래처에 알려서 정정 요청.

**Q20. 앱이 느려요 / 버튼이 안 눌러져요.**

A. 해결 순서:
1. 브라우저 새로고침 (Ctrl + R 또는 Cmd + R)
2. 브라우저 캐시 비우기 (브라우저 설정 → 캐시 삭제)
3. 다른 브라우저 시도 (크롬, 엣지 등)
4. 서포트 연락 (아래 지원 연락처)

|-----------|------|--------|

| 상품명이 정확히 같나? | 상품명 불일치 | DeliveryList K열과 등록 상품명 비교 (띄어쓰기 포함) |
| 거래처 양식이 등록되어 있나? | 거래처 미등록 | "거래처 양식 설정"에서 추가 |
| 셀 위치가 맞나? | 셀 위치 오류 | 거래처 엑셀 파일에서 실제 셀 위치 재확인 |

**단계별 해결:**

1. DeliveryList 다시 확인
   ```
   쿠팡 로켓그로스 → 주문관리 → DeliveryList 다운로드
   K열(상품명) 확인: "콜라비 (당일품)" 같은 정확한 명칭
   ```

2. 앱의 "상품·양식 설정"으로 이동
   ```
   상품 탭 → 등록된 상품 확인
   상품명이 K열과 **정확히 일치**하는지 확인
   ```

3. 일치하지 않으면 수정 또는 재등록
   ```
   상품 수정 → 상품명을 DeliveryList와 동일하게 변경
   저장
   ```

4. DeliveryList 다시 업로드
   ```
   "DeliveryList 처리" → 파일 다시 업로드
   발주서 재생성
   ```

#### 증상 2: "운송장이 매칭되지 않아요"

**상황:**
```
거래처 회신 파일 업로드
→ "3건 매칭 실패" 오류
```

**원인 진단:**

| 체크 항목 | 증상 | 해결책 |
|-----------|------|--------|
| 주문번호 오타 | 회신에 "12345678" / 발주서에 "12345678X" | 거래처에 확인해서 정정 요청 |
| 상품명 다름 | 발주서: "콜라비" / 회신: "콜라비_특품" | 거래처 회신 파일 수정 후 재업로드 |
| 수량 불일치 | 발주: 50kg / 회신: 48kg | 거래처에 불일치 사유 확인 |

**단계별 해결:**

1. 실패 목록 확인
   ```
   "일괄 운송장 입력" → "실패 목록" 클릭
   각 실패 사유 확인
   ```

2. 거래처에 연락
   ```
   "주문번호 확인", "상품명 정정", "수량 조정" 요청
   수정된 회신 파일 받기
   ```

3. 수정된 파일 다시 업로드
   ```
   파일 선택 → 업로드 → 재 처리
   ```

4. 계속 실패하면 수동 입력
   ```
   발주서 옆 "수동 입력" 버튼
   운송장번호 직접 입력
   ```

#### 증상 3: "쿠팡 API 연동에 자꾸 실패해요"

**상황:**
```
쿠팡 API 키 입력
→ "연동 실패" 또는 "인증 오류"
```

**원인 진단:**

| 체크 항목 | 확인 방법 |
|-----------|----------|
| API 키가 맞나? | 쿠팡 개발자 센터에서 복사해서 비교 |
| 앞뒤 공백은? | 복사할 때 공백 없는지 확인 |
| 쿠팡이 제공한 형식 맞나? | 키 형식 (예: "sk_live_...") 확인 |
| 쿠팡 API가 활성화되나? | 쿠팡 상점 설정에서 API 활성 여부 확인 |

**단계별 해결:**

1. 쿠팡 개발자 센터 재확인
   ```
   쿠팡 로켓그로스 → 관리 → 개발자 센터
   → API 인증 정보 (또는 개발자 도구)
   → Key 및 Secret 복사 (공백 주의!)
   ```

2. 앱에 다시 입력
   ```
   좌측 메뉴 → 설정 → 쿠팡 API 키
   → 기존 내용 삭제 후 새로 붙여넣기
   → 저장
   ```

3. 계속 실패하면 쿠팡 확인
   ```
   쿠팡 고객센터: 1670-6001
   API 활성화 상태 문의
   ```

#### 증상 4: "마진율 계산이 잘못된 것 같아요"

**상황:**
```
마진방어 페이지에서
마진율: -50% (음수!)
```

**원인:**
```
쿠팡 판매가 < 거래처 공급가
예: 판매가 ₩3,000, 공급가 ₩6,000
```

**해결:**

1. 즉시 조치 필요 (손실 확대 방지)
   ```
   쿠팡 로켓그로스 → 상품관리 → 가격 인상
   또는 상품 일시 중단
   ```

2. 공급가 확인
   ```
   거래처에 현재 공급가 확인 요청
   공급가 인상 사유 파악
   ```

3. 향후 대응
   ```
   - 거래처 변경 (더 저렴한 곳)
   - 판매가 재책정
   - 상품 단가 검토
   ```

### 일반 기술 이슈

#### 로그인이 안 돼요

**해결 순서:**
1. 이메일/비밀번호 맞는지 다시 확인
2. 대소문자 확인 (비밀번호는 대소문자 구분)
3. Caps Lock 확인
4. 브라우저 캐시 비우고 재시도
5. 다른 브라우저 시도
6. 비밀번호 찾기로 재설정

#### 파일이 안 올라가요

**해결 순서:**
1. 파일 크기 확인 (50MB 이상이면 분할 필요)
2. 파일 형식 확인 (.xlsx 또는 .xls만 가능, .csv 불가)
3. 파일명에 한글이 있으면 영문으로 변경 시도
4. 다른 브라우저에서 시도
5. 인터넷 연결 확인

#### "권한 없음" 오류가 나요

**원인:**
- 다른 사용자의 데이터에 접근하려고 함
- 로그인이 풀렸을 수 있음

**해결:**
1. 로그아웃 후 다시 로그인
2. 본인의 계정 맞는지 확인
3. 계정을 잘못 선택했으면 올바른 이메일로 로그인
