## 0. 전략 요약 (TL;DR)

농산물 위탁셀러는 "**제철에 몰아서 일하고, 비철에 쉰다**". 일반 SaaS의 균일한 그로스 모델이 안 맞는다. 우리의 그로스 엔진은 **(1) 제철 수요 급증기에 신규 획득을 집중**하고, **(2) 한 번 들어온 셀러를 주문 주기(매일/격일)에 묶어 습관화**하며, **(3) "한도 도달" 순간을 페이월 전환점으로** 삼는 3박자다.

- **북극성 지표(NSM):** **WAPS — Weekly Active Processing Sellers** (주간 1건 이상 발주서 또는 운송장 처리를 완료한 셀러 수). 매출·리텐션·획득을 동시에 설명하는 단일 지표.
- **Aha Moment:** 가입 후 **첫 발주서 자동 생성 성공** (목표: 가입→10분 이내, 활성화율 60%+).
- **핵심 전환 트리거:** Free 한도(월 50건/1상품) 도달 → 시즌 피크 직전 = 최적 업셀 타이밍.
- **3개월 목표:** 가입 활성화율 60%+, Free→Pro 전환율 15%+, Pro 월 리텐션 70%+.

```
[커뮤니티/검색/추천] → 랜딩 → 30초 가입(카카오) → 샘플로 첫 발주서(Aha)
        → 매일 주문 처리 습관화 → 한도 도달 → Pro 전환 → 발주서 브랜드 노출 → 추천
                ↑__________________ 시즌 리인게이지먼트 ___________________|
```

## 1. Acquisition (획득)

### 1.1 타겟의 진짜 위치 — "어디서 농산물 위탁셀러를 만나는가"

P1(농산물 멀티채널 셀러)은 대형 광고로 잡히지 않는다. 이들은 **셀러 정보 커뮤니티에 상주하며, 제철 소싱 정보를 검색**한다. 채널을 "내가 통제 가능한 정도 × 타겟 밀도 × CAC"로 평가한다.

| 채널 | 타겟 밀도 | 통제도 | 예상 CAC | 우선순위 | 비고 |
|---|---|---|---|---|---|
| **셀러 카페/커뮤니티** (네이버 카페: 쿠팡셀러·셀러오션·온라인셀러, 아이보스) | ★★★★★ | 중 | 낮음 | **1순위** | 후기/꿀팁 글 + 자연 노출. 광고 글 금지 규정 주의 |
| **검색 SEO** (네이버·구글: "쿠팡 발주서 양식", "운송장 일괄 등록") | ★★★★☆ | 높음 | 매우 낮음(장기) | **1순위** | 구매의도 키워드. 누적 자산 |
| **유튜브** (셀러 노하우 채널 협찬/직접) | ★★★★☆ | 중 | 중 | **2순위** | "발주 5분컷" 데모 영상이 강력 |
| **당근 비즈/지역** | ★★★☆☆ | 중 | 낮음 | **2순위** | 소상공인·소규모 유통 밀집. 지역 산지 셀러 |
| **블로그/브런치** (자체 운영) | ★★★☆☆ | 높음 | 낮음(장기) | **2순위** | SEO 보조 + 신뢰 자산 |
| **제휴** (쿠팡 강의/컨설팅·산지 도매상·택배 영업소) | ★★★★☆ | 낮음 | 중 | **3순위** | B2B2C, 한 명이 다수 셀러 보유 |
| **유료 광고** (네이버 파워링크·메타) | ★★☆☆☆ | 높음 | 높음 | **후순위** | PMF·전환율 검증 후 확대 |

> **우선순위 원칙:** 초기엔 **CAC 낮고 신뢰 높은 채널(커뮤니티+SEO)** 집중 → PMF 신호 확인 후 **유튜브·제휴**로 확장 → 단위경제(LTV/CAC ≥ 3) 검증되면 유료광고. 1인/소상공인은 광고보다 **"같은 셀러의 후기"**에 압도적으로 반응.

### 1.2 랜딩 페이지 — 메시지 & CTA

기존 `/pricing`(PricingPage, 공개) 외에 **전환 전용 랜딩(`/` 또는 `/lp/nongsanmul`)** 신설 권장.

**핵심 메시지 (Hero):**
> # 쿠팡·토스·태무 발주, 하루 3시간 → **5분**
> 농산물 셀러를 위한 발주서·운송장 자동화.
> **주문 엑셀만 올리면, 거래처별 발주서가 자동 완성.**
> [▶ 무료로 첫 발주서 만들기] (카카오 30초 가입) [▶ 1분 데모 보기]

**메시지 위계 (스크롤 순서):**
1. **Hero** — 위 카피. CTA 2개(주 CTA: 무료 시작 / 보조: 데모).
2. **Pain 공감** — "콜라비·참외·고구마마다 옵션 표기가 다르고, 거래처마다 양식이 달라서…" (타겟이 자기 얘기로 느끼게).
3. **Before/After** — 좌: 엑셀 수작업 지옥 스샷 / 우: 클릭 한 번 결과물. **GIF 데모**.
4. **농산물 특화 증명** — "품목별 등급·중량 옵션 변환 내장" (범용 셀러툴과의 결정적 차별점, PRD §3).
5. **신뢰** — 처리 성공률 99%+, 멀티테넌트 보안(RLS), 실사용 셀러 후기/처리 건수 카운터.
6. **요금** — Free로 바로 체험 강조, Pro ₩29,000 가치(시간 환산: "월 ₩29,000 = 하루 3시간 절약").
7. **최종 CTA** — "오늘 주문부터 5분 안에. 무료로 시작."

**CTA 카피 A/B 후보:**
- A: "무료로 첫 발주서 만들기"
- B: "오늘 주문 5분컷 시작하기"
- C: "내 거래처 양식으로 변환해보기"

> **CTA 원칙:** "회원가입" 같은 비용 단어 금지. **"첫 발주서 만들기"** 같이 *얻는 가치*로 표현. 가입 마찰 최소화 = 카카오 우선.

### 1.3 콘텐츠 마케팅 — 농산물 셀러 팁 (SEO 자산 + 신뢰)

구매의도·정보탐색 키워드를 노린 **"검색에 걸리는 실전 팁"**. 각 글 말미에 자연스러운 제품 CTA.

| 콘텐츠 주제 | 타겟 키워드 | 퍼널 단계 | 형식 |
|---|---|---|---|
| 쿠팡 로켓그로스 발주서 양식 만드는 법 (+ 템플릿 무료배포) | "쿠팡 발주서 양식" | TOFU→리드 | 블로그+다운로드 |
| 운송장 번호 엑셀로 일괄 등록하는 3가지 방법 | "운송장 일괄 등록" | MOFU | 블로그+영상 |
| 농산물 위탁판매 정산·마진 계산 (면세 처리 포함) | "농산물 위탁 정산", "농산물 부가세 면세" | TOFU | 블로그 |
| 제철 농산물 캘린더 — 언제 뭘 팔아야 하나 | "제철 농산물 시기" | TOFU(시즌훅) | 인포그래픽 |
| 콜라비/참외/고구마 옵션·등급 표기 표준화 | 롱테일 품목명 | MOFU | 가이드 |
| 쿠팡·토스·태무 멀티채널 운영 체크리스트 | "멀티채널 셀러" | MOFU | 체크리스트 |

> **콘텐츠 → 리드 전환 장치:** 무료 엑셀 템플릿 다운로드 시 이메일 수집(리드마그넷) → 뉴스레터 → 제품 가입 너처링.

### 1.4 Acquisition 목표 지표

- 랜딩 방문→가입 전환율 **8%+** (콜드 트래픽), **20%+** (커뮤니티/추천 트래픽)
- 채널별 CAC 추적, 블렌디드 CAC < 예상 LTV의 1/3
- SEO: 6개월 내 핵심 키워드 10개 1페이지 진입, 월 오가닉 방문 가설치 설정 후 추적
- 월 신규 가입 — 시즌 피크월은 비철월 대비 2~3배 목표

## 2. Activation (활성화)

### 2.1 Aha Moment 정의 (정밀)

> **"가입 후 첫 발주서(또는 운송장 매칭)를 자동 생성해 다운로드까지 성공한 순간."**

이때 셀러는 "수작업 3시간 → 클릭 한 번"을 *체감*한다. 이 순간 도달률 = **활성화율(목표 60%+, PRD §12)**. 빠를수록 리텐션이 높다 → **가입→Aha 10분 이내**(PRD Goal 1).

**활성화 단계 분해 (각 단계 이탈률 측정):**
```
가입 완료 → 샘플/실파일 업로드 → 품목·거래처 인식 → 발주서 생성 성공 → 다운로드(=Aha)
   (drop)         (drop)              (drop)            (drop)
```

### 2.2 가입→첫 가치 시간 단축 전술

1. **샘플 파일 즉시 체험 (결제·실데이터 전):** 가입 직후 "내 파일이 없어도 됩니다 — **샘플로 1초 만에 결과 보기**" 버튼. PRD User Story("샘플 파일로 즉시 체험")와 직결. → 빈 계정에서도 Aha 선체험.
2. **카카오 30초 가입:** 이메일 인증 단계 제거, OAuth 우선 (PRD §6).
3. **품목 프리셋 제공:** 콜라비·참외·고구마 등 **기성 품목 25종 프로세서**를 온보딩에서 "내 품목 고르기"로 즉시 선택 → 양식 셋업 0초.
4. **첫 업로드 가이드 오버레이:** 어디에 무엇을 올리는지 화살표 코치마크.
5. **실패해도 Aha:** 매칭 실패 시 "이 행만 확인하면 됩니다" 명확 표시(이미 일부 구현, PRD P1-5) — 좌절 대신 신뢰.

### 2.3 온보딩 체크리스트 (인앱)

가입 직후 대시보드 상단 진행률 바 (Gamified). **완료할 때마다 Free 사용 가치를 체감**시킨다.

```
□ 1. 카카오로 가입 (자동 완료)
□ 2. 내 판매 채널 선택 (쿠팡 / 토스 / 태무)
□ 3. 첫 품목 선택 또는 등록  → /my/products
□ 4. 샘플 또는 실제 주문파일 업로드 → 첫 발주서 생성  ★Aha
□ 5. 운송장 회신 파일로 매칭 1건 성공
□ 6. (선택) 쿠팡 API 연동 — 운송장 자동 등록
```
> 체크리스트 4번(Aha) 완료가 **활성화 정의**. 5번까지 = "완전 활성화(Activated+)". 미완료 항목은 Day1/Day3 이메일·인앱 넛지로 리마인드.

### 2.4 빈 계정(Empty State) 방지

- **빈 대시보드 금지:** 데이터 0일 때 "여기에 처리 결과가 쌓입니다 — 지금 샘플로 시작" CTA + 데모 미리보기.
- **품목 0일 때:** "내 품목이 없네요 — 콜라비/참외/고구마 중 골라보거나 직접 등록" 원클릭 프리셋.
- **첫 세션 이탈 시:** 1시간 내 미완료자에게 "막히신 부분 있나요? 1분 영상" 이메일.

### 2.5 Activation 목표 지표

- 가입→Aha(첫 발주서) **60%+**, 그중 **70%는 10분 이내**
- 가입→완전활성화(운송장 매칭까지) **35%+**
- 온보딩 체크리스트 4단계 완료율 추적, 단계별 이탈 히트맵

## 3. Retention (유지)

### 3.1 습관화 루프 — 주문 주기에 제품을 묶는다

농산물 셀러의 **자연 주기 = 주문 처리 주기(매일~격일)**. 제품을 이 루프의 *고정 단계*로 만든다.

```
[채널에 주문 들어옴(외부 트리거)]
   → 알림: "오늘 처리할 주문 N건 있어요"(이메일/인앱)
   → 발주서 생성(행동)
   → "3시간 → 4분, 오늘도 절약!"(가변 보상 — 절약 시간 표시)
   → 운송장 회신 처리 → 정산에 누적(투자 — 데이터가 쌓일수록 떠나기 어려움)
   → 반복
```
> Hook Model(트리거→행동→보상→투자) 적용. **투자 축적(누적 정산·마진 이력·등록 품목)**이 전환비용이 되어 리텐션을 만든다.

### 3.2 주간 사용량 / 정산 리포트 이메일 (핵심 리텐션 자산)

매주 월요일 발송. **"당신이 우리로 얼마나 이득 봤는지"**를 숫자로.

```
제목: [발주메이트] 지난주 {닉네임}님은 3시간 28분 아꼈어요 ⏱️

지난주 요약 (5/26~6/1)
• 처리한 발주서: 42건
• 등록한 운송장: 38건
• 절약 시간(추정): 3시간 28분  ← 핵심 보상 숫자
• 가장 많이 팔린 품목: 꿀고구마 5kg

📊 이번주 정산 추이 [대시보드 보기]
🌱 시즌 알림: 다음주 참외 성수기 시작 — 미리 거래처 양식 점검하세요
```
> 절약 시간·처리 건수 = **가치 재확인(Value Reinforcement)**. Pro 사용자에겐 정산·마진 인사이트 추가. 이 메일 자체가 주간 재방문 트리거.

### 3.3 인앱 알림

| 알림 | 트리거 | 목적 |
|---|---|---|
| "오늘 처리할 주문 N건" | 일일/연동 시 | 습관 트리거 |
| "운송장 매칭 실패 3건 — 확인 필요" | 처리 후 | 신뢰·완결성 |
| "꿀고구마 옵션이 새로 추가됐어요" | 품목 변동 | 재방문 |
| "이번달 사용량 42/50건 (84%)" | 한도 임박 | **전환 트리거(→Revenue)** |
| "공급가 변동 — 콜라비 역마진 위험" | 가격룰 | 가치 심화 |

### 3.4 시즌 알림 (제철 품목) — 농산물 SaaS만의 무기

제철 캘린더와 연동해 **"지금 준비해야 할 품목"**을 선제 푸시. 비철기 휴면 셀러를 깨우는 최강 트리거. (상세 §8)

### 3.5 미사용자 리인게이지먼트 (재활성화 시퀀스)

```
D+3 무행동:  "막히신 부분 있나요? 1분 영상으로 첫 발주서"
D+7 무행동:  "샘플로 1초 체험 — 클릭 한 번이면 됩니다"
D+14 무행동: "이번주 신규 품목 + 제철 캘린더" (가치 콘텐츠)
D+30 무행동: "{제철품목} 성수기 시작 — 다시 시작하면 첫 달 ○○ 혜택"(시즌훅 + 인센티브)
```

### 3.6 Retention 목표 지표

- **Pro 월 리텐션 70%+** (PRD §12), Free 포함 4주 리텐션 추적
- WAU/MAU(스티키니스) — 주문 주기 특성상 **0.4+** 목표
- 주간 리포트 이메일 오픈율 35%+/클릭 8%+
- 코호트별 리텐션 커브(가입 월별), 시즌 코호트 vs 비철 코호트 비교

## 4. Revenue (매출)

> 본 절은 `02-monetization-pricing.md`의 **선행 가설**. 가격·플랜 상세 확정은 해당 문서에서. 여기선 **전환 퍼널·페이월·업셀 트리거·실험 포인트**에 집중.

### 4.1 요금제 (PRD §11 / PROJECT_SPEC §9 기준)

| 플랜 | 가격 | 한도 | 역할 |
|---|---|---|---|
| **Free** | ₩0 | 상품 1개, 월 50건 | 획득·체험·Aha 전달 |
| **Pro** | ₩29,000/월 | 무제한 상품, 월 3,000건 | 주 수익원(P1) |
| **Team** | 미정(future) | 다중 사용자·API | 유통업자 P2 확장 |

### 4.2 전환 퍼널 — 단계 정의 & 측정

```
방문(Visit)
 → 가입(Signup)                    [Acquisition→Activation 경계]
 → 활성화(첫 발주서 = Aha)          ★ 전환의 선행조건
 → 습관 형성(주 2회+ 처리)
 → 한도 근접(월 40/50건 ≈ 80%)     ★ 페이월 노출 최적점
 → 한도 도달(50/50)               ★ 강제 결정 지점
 → Pro 전환(Paid)
 → 유지 결제(Retained Paid)
```

| 단계 전환 | 측정 지표 | 목표 |
|---|---|---|
| 방문→가입 | Signup rate | 8~20% |
| 가입→활성화 | Activation | 60%+ |
| 활성화→습관 | Week2 retained | 50%+ |
| 활성화→Pro | **Free→Pro 전환** | **15%+** (3개월, PRD Goal 4) |
| Pro→유지 | 월 리텐션 | 70%+ |

### 4.3 페이월 & 업셀 트리거

**전환은 "기능 잠금"이 아니라 "가치 입증 후 한계 도달"에서 일어난다.** Free에서 Aha를 충분히 주고, **성장하는 셀러가 한도에 막히는 순간** 자연 전환.

| 트리거 | 노출 시점 | 카피 예시 | 전환 의도 |
|---|---|---|---|
| **한도 임박(80%)** | 월 40/50건 | "이번달 40/50건 사용 — 곧 한도예요. 성수기 놓치지 않으려면 Pro로 무제한 처리" | 예방적 업셀 |
| **한도 도달(100%)** | 51번째 시도 | "월 50건을 다 쓰셨어요! Pro(₩29,000)로 지금 바로 이어서 처리하기" | 강제 결정점 |
| **2번째 품목 추가** | Free 1상품 초과 | "품목을 늘리시는군요 — Pro는 품목 무제한입니다" | 가치 확장 |
| **Pro 전용 기능 클릭** | 마진/정산 대시보드, 쿠팡 API | "마진 방어·정산 분석은 Pro 기능 — 14일 무료로 체험" | 기능 욕구 |
| **시즌 피크 직전** | 제철 D-7 | "참외 성수기 시작 전, 무제한 Pro로 준비하세요" | 시즌 FOMO |
| **절약시간 누적** | 주간 리포트 | "지난달 14시간 아끼셨어요 — Pro면 더" | ROI 설득 |

> **페이월 UX 원칙:** 차단(blocking)이 아니라 *연속성 제안*. 작업 중인 파일·맥락 유지한 채 "지금 결제하면 바로 이어서". 토스 구독 결제는 1~2탭 내 완료.

### 4.4 가격 실험 포인트

1. **Free 한도 수준** (50건이 적정? 30/50/70건 A/B) — 너무 높으면 전환 안 됨, 너무 낮으면 Aha 전 이탈.
2. **연간 결제 할인** (예: 연 ₩290,000 = 2개월 무료) — LTV·현금흐름 개선, 리텐션 락인.
3. **무료체험(Pro 14일)** vs **Freemium** — 어느 쪽 전환율이 높은지 코호트 비교.
4. **건수 기반 종량제** 옵션 (PRD Open Question) — 시즌 편중 셀러용 "쓴 만큼" 과금 가설.
5. **시즌 프로모션** 가격 탄력성 측정 (성수기 정가 vs 비철 할인 유입).
6. **앵커링** — `/pricing`에서 Team(미정)을 상단 배치해 Pro를 "합리적 선택"으로 보이게.

### 4.5 Revenue 목표 지표

- Free→Pro **15%+**(3개월), MRR 성장률 월 추적
- ARPU, 한도도달→전환율(이 구간이 가장 높아야 정상)
- 무료체험 시작→유료 전환율, 환불·다운그레이드율
- LTV/CAC ≥ 3 (유료광고 확대 게이트)

## 5. Referral (추천)

1인 셀러는 **같은 셀러의 추천**을 가장 신뢰. 추천 루프를 제품에 내장.

### 5.1 추천 보상 프로그램

- **양방향 보상(Double-sided):** "친구 초대 → 친구 가입+첫 발주서 생성 시 **둘 다 Pro 1개월 무료**(또는 처리 건수 보너스)."
- **트리거 타이밍:** Aha 직후·주간 리포트("3시간 아꼈어요") 직후 = 만족도 최고점에 추천 요청.
- **추적:** 고유 초대 링크/코드, 추천인-피추천인 매핑 테이블, 보상 지급 자동화.

### 5.2 바이럴 루프 — 발주서에 브랜드 노출 (제품 주도 바이럴)

> 셀러가 만드는 **발주서·운송장 엑셀이 거래처(산지 공급사)에게 매일 전달**된다. 이 파일이 곧 광고 지면.

- **Free 플랜 산출물 푸터/워터마크:** "이 발주서는 **발주메이트**로 자동 생성됨 — [무료 시작]". 거래처(다른 셀러/유통업자일 수 있음)와 그 셀러의 다른 동료에게 노출.
- **Pro는 브랜딩 제거/자기 브랜드 삽입** = 부가 전환 동기(화이트라벨 욕구 → Pro/Team 업셀).
- **거래처 역유입:** 산지 공급사는 여러 셀러와 거래 → "다른 거래처도 이걸로 받고 싶다" 유입 경로.

> ⚠️ 거래 문서에 워터마크는 신뢰·전문성 우려가 있으니, **미세하게/Free 한정/제거 가능(Pro)**으로 설계하고 A/B로 거부감 측정.

### 5.3 비공식 추천 촉진

- 커뮤니티 공유용 **"내 절약시간 카드"** 이미지 생성("이번달 14시간 절약" → SNS/카페 공유 유도).
- 추천 NPS 연계: NPS 9~10 응답자에게 즉시 추천 요청.

### 5.4 Referral 목표 지표

- 추천 가입 비율(전체 신규 중) 10%+ 목표, 바이럴 계수(K) 추적
- 초대 발송→가입→활성화 전환율, 추천 경유 사용자의 리텐션(보통 더 높음) 비교

## 6. 분석 · 계측 설계 (Instrumentation)

### 6.1 북극성 지표 (North Star Metric)

> **NSM = WAPS (Weekly Active Processing Sellers)**
> *주간 1건 이상 발주서 또는 운송장 처리를 성공 완료한 고유 셀러 수.*

- **왜 이 지표인가:** 처리=핵심 가치 전달 행위. 처리하는 셀러가 늘면 → 활성화·리텐션·전환·매출이 함께 성장. 허영지표(가입 수)가 아닌 **가치 전달 빈도**를 측정.
- **보조(Input) 지표:** 신규 활성화 수, 주간 처리 건수/셀러, 한도도달 셀러 수, Pro 비중.

### 6.2 추적 핵심 이벤트 (Event Taxonomy)

`snake_case` 표준. 모든 이벤트에 공통 속성: `user_id`, `plan`(free/pro), `timestamp`, `channel`(쿠팡/토스/태무), `session_id`.

| 이벤트명 | 발생 시점 | 핵심 속성 | 퍼널 단계 |
|---|---|---|---|
| `signup_completed` | 가입 완료 | `method`(kakao/google/email), `referral_code?` | Acquisition |
| `onboarding_step_completed` | 체크리스트 단계 | `step`(1~6) | Activation |
| `sample_processed` | 샘플 체험 처리 | `product_preset` | Activation |
| `file_uploaded` | 주문파일 업로드 | `file_type`(delivery/reply), `row_count` | Activation |
| `purchase_order_generated` | **발주서 생성 성공** ★Aha | `product`, `vendor`, `order_count`, `duration_ms` | Activation |
| `tracking_matched` | 운송장 매칭 완료 | `matched`, `failed_count` | Activation/Retention |
| `coupang_api_registered` | 쿠팡 API 운송장 등록 | `count`, `success` | Retention |
| `product_created` | 커스텀 품목 등록 | `is_preset` | Activation/Retention |
| `weekly_report_opened` | 리포트 이메일 오픈 | `saved_minutes` | Retention |
| `usage_limit_warning_shown` | 한도 80% 노출 | `used`, `limit` | Revenue |
| `usage_limit_reached` | **한도 100% 도달** | `used`, `limit` | Revenue |
| `paywall_viewed` | 페이월 노출 | `trigger`(limit/feature/season/2nd_product) | Revenue |
| `upgrade_started` | 결제 플로우 시작 | `from_plan`, `trigger` | Revenue |
| `upgrade_completed` | **Pro 전환 완료** | `plan`, `billing_cycle`, `trigger` | Revenue |
| `subscription_cancelled` | 해지 예약 | `reason?`, `tenure_days` | Churn |
| `referral_invited` | 초대 발송 | `channel` | Referral |
| `referral_converted` | 피추천인 활성화 | `referrer_id` | Referral |
| `reengagement_clicked` | 윈백 메일 클릭 | `days_inactive`, `campaign` | Retention |

> **구현 메모:** 백엔드(`usage_logs`, `billing_events` 테이블 — PRD §8/PROJECT_SPEC §10 기존 자산)를 이벤트 소스로 활용. 프론트 이벤트는 경량 트래커(예: 자체 `/api/events` 엔드포인트 → Postgres, 또는 PostHog/Amplitude 도입). RLS로 테넌트 격리 유지.

### 6.3 퍼널 정의

1. **활성화 퍼널:** `signup_completed` → `file_uploaded` → `purchase_order_generated`(Aha) → `tracking_matched`.
2. **전환 퍼널:** `purchase_order_generated` → (반복 처리) → `usage_limit_warning_shown` → `paywall_viewed` → `upgrade_completed`.
3. **추천 퍼널:** `referral_invited` → `signup_completed(referral)` → `referral_converted`.

### 6.4 코호트 정의

- **가입 주/월별 코호트** → 리텐션 커브(W1~W12), 활성화율 추이.
- **시즌 코호트:** 성수기 가입자 vs 비철 가입자 — LTV·리텐션 차이로 시즌 획득 ROI 판단.
- **채널 코호트:** 유입 채널별 활성화·전환·LTV (채널 예산 배분 근거).
- **플랜 코호트:** Free / 무료체험 / Pro 직행 — 경로별 잔존·매출.
- **품목 코호트:** 주력 품목별(고구마/콜라비/참외…) 처리량·리텐션.

## 7. 이탈 시그널 · 윈백 (Churn Prediction & Win-back)

### 7.1 이탈 예측 신호 (선행 지표)

| 신호 | 의미 | 임계 예시 |
|---|---|---|
| **주간 처리 0건** (직전 2주+ 활성) | 습관 붕괴 시작 | 7일 무처리 |
| **로그인 빈도 급감** | 관심 이탈 | 평소 대비 -50% |
| **주간 리포트 미오픈 연속** | 가치 재인식 실패 | 3주 연속 |
| **처리량 추세 하락** | 사업 축소 or 경쟁 도구 이동 | 3주 연속 감소 |
| **매칭 실패 후 미해결 방치** | 좌절·불신 | 실패건 7일+ 방치 |
| **결제 실패/카드 만료** | 비자발적 이탈(Involuntary) | 빌링키 오류 |
| **해지 페이지 방문** | 명시적 이탈 임박 | 즉시 |

> **헬스 스코어:** 위 신호를 가중 합산해 셀러별 `churn_risk`(green/yellow/red). 비철기 자연 휴면과 진짜 이탈을 **시즌 보정**해 구분(제철 끝난 품목 셀러의 무처리는 정상).

### 7.2 윈백 캠페인

| 세그먼트 | 트리거 | 액션 |
|---|---|---|
| **Yellow(위험 초기)** | 7일 무처리 | 인앱+이메일: "처리할 주문 없으신가요? 다음 제철 {품목} 준비 팁" |
| **Red(이탈 임박)** | 14일+ 무처리 | "오랜만이에요 — 그동안 추가된 기능 + 첫 발주서 다시 1초 체험" |
| **해지 직전(결제 유지 중)** | 해지 페이지 방문 | **해지 방어 모달:** 사유 선택 → 사유별 대응(가격→연간할인/일시정지, 비철→**구독 일시정지**, 기능부족→대안 안내) |
| **해지 완료자** | 해지 후 30/60일 | "성수기 돌아왔어요 — 첫 달 ○○ 혜택으로 복귀" |
| **비자발적 이탈** | 결제 실패 | 카드 갱신 안내(스마트 리트라이 + 이메일), 유예기간 |

> **비철 셀러 핵심 장치 — "구독 일시정지(Pause)":** 완전 해지 대신 **시즌 종료 시 일시정지 → 다음 제철에 자동 재개** 제안. 농산물 시즌성 특성상 해지 방어의 결정적 무기. (해지율을 구조적으로 낮춤)

### 7.3 Churn 목표 지표

- 월 해지율(Pro) < 5%, 그중 비자발적 이탈 회수율 40%+
- 윈백 메일→재활성화율 추적, 일시정지→재개율
- 헬스스코어 Red 셀러의 30일 내 이탈 적중도(모델 정확도)

## 8. 시즌성 그로스 (Seasonal Growth) — 농산물 SaaS의 결정적 레버

농산물은 **제철 = 주문 폭증 = 셀러의 도구 needs 최고조**. 이때 **획득·활성화·전환을 의도적으로 몰아친다**. 비철기는 콘텐츠·관계 빌딩·일시정지 유지로 버틴다.

### 8.1 제철 캠페인 캘린더 (예시 — 한국 주요 산지 품목)

| 시기 | 제철·성수 품목 | 그로스 액션 |
|---|---|---|
| **3~5월(봄)** | 두릅·명이나물·딸기, 참외 시작 | 봄나물 셀러 신규 획득 캠페인, "참외 성수기 D-30 준비" 콘텐츠 |
| **6~8월(여름)** | 참외·수박·토마토·콜라비 **(최대 성수)** | **연중 최대 획득·전환 푸시**, 한도 임박 업셀 집중, 시즌 프로모션 |
| **9~11월(가을)** | 고구마·사과·감·배 **(추석 특수)** | 추석 선물세트 발주 폭증 대응, 신규 획득 2차 피크, 거래처 양식 점검 캠페인 |
| **12~2월(겨울)** | 귤·딸기·견과, 설 특수 | 설 명절 폭증 대응, 비철 셀러 일시정지/재개 유도, 콘텐츠로 관계 유지 |

> **품목별 셀러 세그먼트화:** 등록 품목으로 셀러를 분류 → **각 품목 성수기 D-30/D-7에 맞춤 알림**("고구마 셀러님, 추석 발주 폭증 전 Pro로 무제한 준비"). §3.4·§4.3·§7.2와 연결.

### 8.2 시즌 플레이북 (반복 적용)

```
D-30: 제철 콘텐츠 발행(SEO/커뮤니티) + 해당 품목 휴면 셀러 윈백 시작
D-14: "성수기 준비" 인앱/이메일, 거래처 양식 점검 리마인드
D-7:  Pro 시즌 프로모션 오픈 + 페이월 시즌 트리거 ON("성수기 무제한")
피크:  실시간 처리량 모니터링, 지원 강화(폭증기 이탈=치명), 안정성 우선
D+7:  "이번 시즌 ○○건 처리, ○시간 절약" 리포트 + 추천 요청(만족 최고점)
비철:  일시정지 제안, 다음 시즌 캘린더 예고, 콘텐츠로 리텐션
```

### 8.3 Seasonal 목표 지표

- 시즌 피크월 신규 가입 = 비철월 대비 **2~3배**
- 시즌 전환율(피크기 Free→Pro) > 연평균 전환율
- 시즌 코호트 LTV vs 비철 코호트, 일시정지→재개 전환율 60%+
