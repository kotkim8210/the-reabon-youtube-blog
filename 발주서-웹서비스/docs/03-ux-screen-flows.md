## 1. 정보구조(IA) 및 내비게이션

### 1.1 전체 사이트맵

```
발주메이트
├── /                        랜딩 페이지 (비로그인)

├── /verify-email            이메일 인증 대기
├── /onboarding              온보딩 위저드 (신규 가입 후 1회)

├── /dashboard               메인 대시보드           [인증 필요]

├── /orders                  발주서 생성

### 1.2 내비게이션 구조

#### 인증 전 (랜딩/로그인/회원가입)
- 최상단 고정 TopBar만 노출. 사이드바 없음.

#### 인증 후 (앱 내부)
- **레이아웃**: 좌측 고정 사이드바(240px) + 상단 TopBar(64px) + 우측 콘텐츠 영역
- **모바일(< 768px)**: 사이드바 숨김, 하단 탭바(5개 핵심 메뉴) + 햄버거로 전체 메뉴 드로어

```
┌──────────────────────────────────────────────────────────┐
│  TopBar: [로고] [플랜 배지] ············ [알림] [계정 아바타] │
├──────────┬───────────────────────────────────────────────┤
│          │                                               │
│ Sidebar  │  콘텐츠 영역                                   │
│  240px   │                                               │
│          │                                               │
│ [홈]     │                                               │
│ [발주서] │                                               │
│ [운송장] │                                               │
│ [쿠팡API]│                                               │
│ [마진]   │                                               │
│ [판매통계]│                                               │
│ ─────── │                                               │
│ [설정]   │                                               │
│ [구독]   │                                               │
│          │                                               │
└──────────┴───────────────────────────────────────────────┘
```

#### 사이드바 메뉴 항목 명세

| 메뉴 레이블 | 아이콘 | 경로 | 뱃지 조건 |
|---|---|---|---|
| 홈 | `LayoutDashboard` | `/dashboard` | - |
| 발주서 생성 | `FileText` | `/orders` | - |
| 운송장 입력 | `Truck` | `/tracking` | 미처리 건 수 |
| 쿠팡 API 등록 | `Zap` | `/coupang-api` | - |
| 마진방어 | `TrendingUp` | `/margin` | - |
| 판매 통계 | `BarChart2` | `/analytics` | - |
| ─ 구분선 ─ | | | |
| 설정 | `Settings` | `/settings` | - |
| 구독 관리 | `CreditCard` | `/billing` | Free 플랜이면 "업그레이드" 강조 |

#### TopBar 명세

```
[발주메이트 로고]   [Free ▸ 월 50건 중 12건 사용]   ···   [🔔 알림]   [KK 아바타 ▾]
```

- **로고**: 클릭 시 `/dashboard`
- **플랜 배지**: Free면 `bg-amber-100 text-amber-700 rounded-full px-3 py-1` 으로 사용량 표시. Pro면 `bg-emerald-100 text-emerald-700`에 "Pro" 레이블만
- **알림 아이콘**: 미확인 알림 있으면 빨간 dot. 클릭 시 알림 드롭다운(최근 5건)
- **계정 아바타**: 이름 이니셜 또는 소셜 프로필 사진. 클릭 시 드롭다운:
  - 내 계정
  - 구독 관리
  - 로그아웃

## 3. 온보딩 위저드

**목적**: 신규 가입 후 10분 내 첫 발주서 생성 경험을 유도. 이탈 방지.  
**진입 조건**: `profiles.onboarding_completed = false` 인 상태에서 `/dashboard` 접근 시 자동 리다이렉트  
**건너뛰기**: 각 단계에서 "나중에 하기" 가능. 건너뛰면 대시보드에 온보딩 배너 잔류.

### 3.1 위저드 전체 구조

```
Step 1: 환영                     (정보 없음, 클릭만)
Step 2: 채널 선택                (쿠팡·토스·태무 체크박스)
Step 3: 샘플 다운로드 & 체험      (샘플 엑셀 다운로드 → 업로드 → 결과 확인)
Step 4: 첫 발주서 생성            (실제 파일 업로드 또는 샘플로 완료)
Step 5: 완료 & 대시보드 이동
```

### 3.2 위저드 레이아웃

```
┌──────────────────────────────────────────────────────┐
│                   발주메이트 로고           [건너뛰기] │
├──────────────────────────────────────────────────────┤
│                                                      │
│  ●━━━━━○━━━━━○━━━━━○━━━━━○                          │
│  1    2    3    4    5                               │
│  (프로그레스 바)                                      │
│                                                      │
│  ┌──────────────────────────────────────────────┐   │
│  │                                              │   │
│  │              단계별 콘텐츠                    │   │
│  │                                              │   │
│  └──────────────────────────────────────────────┘   │
│                                                      │
│                    [이전]    [다음 →]                 │
└──────────────────────────────────────────────────────┘
```

### 3.3 Step 1: 환영

```
[일러스트: 박스 + 트럭 아이콘]

발주메이트에 오신 것을 환영합니다!

쿠팡·토스·태무 주문을 자동으로 처리하는
발주서·운송장 자동화 서비스입니다.

지금 바로 첫 발주서를 만들어 보세요.
5분이면 충분합니다.

               [시작하기 →]
```

### 3.4 Step 2: 사용 채널 선택

```
어떤 채널에서 판매하고 계신가요? (중복 선택 가능)

☐  쿠팡 로켓그로스 / 쿠팡 일반
☐  토스쇼핑
☐  테무(Temu) 태무

선택 후에도 설정에서 변경할 수 있습니다.
```

- 최소 1개 선택 필수. 미선택 시 "다음" 버튼 비활성
- 선택 정보는 `user_settings.channels` 에 저장

### 3.5 Step 3: 샘플 체험

```
