## 한눈에 보는 순서

```
STEP 0 (지금)      NO1 무료로 써보며 감 잡기 + 크림 사업자/계정 준비
STEP 1 (1~2주)     브랜드리셀OS Phase1: 장부 + 입고스캔 + 마진계산기  ← 여기서 이미 엑셀 탈출
STEP 2 (3~5주)     시세 자동수집(본인세션) + 수익성 시뮬 + 발송관리
STEP 3 (선택)      도매 리스트 AI 분석 (유일한 유료 요소, 아낄 수 있음)
STEP 4 (레벨업 후)  PRO 매크로 자력 구현: 자동입찰·최저가경쟁·보관  ← NO1 PRO를 무료로
```

## STEP 0 — 지금 당장 (돈 0원, 앱 개발 전)

우리 앱을 만들기 전에, **벤치마크(NO1)를 무료로 직접 써보며** 리셀 워크플로우 감을 잡는 단계. 초짜에겐 이게 가장 빠른 학습이다.

- [ ] NO1 셀러센터 **무료 가입** → 무료 소싱툴로 크림/포이즌 시세·재고 보는 법 익히기
- [ ] NO1 무료 매크로(입찰관리·판매내역/발송 다운로드)까지만 사용 (PRO 결제 X)
- [ ] **크림 계정 준비**: 초짜는 레벨1(월정산 200만↓, 수수료 기본 2,500원+6.0%)에서 시작
- [ ] **사업자 등록 검토**: 부가세 환급(매입가의 약 9%)은 일반과세 사업자여야 가능 → 마진의 핵심. 초기부터 등록하면 유리
- [ ] 이때 배운 "무엇이 불편한가"가 곧 우리 앱의 우선순위 → 메모해두기

> 💡 STEP 0만으로도 리셀 자체는 시작 가능. 우리 앱은 이 과정을 **더 빠르고 실수 없게** 만드는 것.

## STEP 1 — 브랜드리셀OS Phase 1 (핵심 MVP, 운영비 0원)

**목표: 엑셀 장부를 버린다.** 구매를 기록하고, 폰으로 송장 스캔해 입고 검수하고, 마진 계산기로 살지 말지 판단.

### 이용자가 실제로 하는 것
1. 로그인(이메일 매직링크) → 내 워크스페이스 생성
2. **마진 계산기**에 매입가 입력 → "크림 팔면 +얼마, 부가세 환급하면 +얼마" 즉시 확인 (초짜용 적자 방어선 강조)
3. 무신사 등에서 산 걸 **구매내역**에 붙여넣기/등록
4. 택배 오면 **폰으로 송장 스캔** → 도착 처리 → 뜯으며 검수(정상/오배송) → 입고 완료
5. "몇 개 안 왔는지" 자동 경고로 누락 0건

### 무료 유지 방법 (전부 무료 티어 안)
| 항목 | 서비스 | 무료 한도 | 초짜 사용량 |
|---|---|---|---|
| 호스팅 | Vercel Hobby | 개인 무료 | ✅ 충분 |
| DB+인증+저장 | Supabase Free | DB 500MB · 인증 5만 MAU · 저장 1GB | ✅ 혼자 쓰면 넘칠 일 없음 |
| 바코드 스캔 | zxing-wasm | 오픈소스 무료 | ✅ 폰 브라우저에서 동작 |
| 도메인 | vercel.app 서브도메인 | 무료 | ✅ (원하면 나중에 도메인 구매) |

→ **STEP 1은 완전 무료.** 결제·요금제 기능 자체를 안 만든다(내부 툴).

## STEP 2 — Phase 2 일부 (시세 자동화 + 수익성, 여전히 0원)

STEP 1이 손에 익으면 데이터 판단을 강화.

- [ ] **시세 자동 수집**: NO1처럼 서버 크롤링(리스크 큼) 대신, **내 크림 세션을 읽는 브라우저 확장/로컬 스크립트**로 본인 계정 데이터만 수집(06_BENCHMARK §5 방식). 혼자 쓰니 남의 비번 위탁 부담 없음 → 서버 비용 0
- [ ] **사업 수익성 시뮬레이터**(F10): 인건비·고정비·원가율 넣고 "매출 얼마부터 흑자인지" 확인 — NO1의 [resell_profit_dashboard](https://no1.certi.life/resell_profit_dashboard.html) 그대로 참고
- [ ] **발송 관리**: 판매주문 모아 송장 스캔으로 일괄 발송 (수기 오타 페널티 제거)

→ 크롤링 서버가 없으니 이 단계도 **추가 비용 0원**.

---

## STEP 3 — 도매 AI 분석 (유일한 유료 요소, 안 써도 됨)

- 도매 카톡 리스트 캡처 → AI가 품번·수량 추출. **여기만 Claude API 비용 발생**.
- **초짜 절약법**: ① 안 쓰고 수동 입력으로 대체 가능 ② 쓰더라도 하루 몇 건이면 월 몇백~몇천 원 수준 ③ 정말 아끼려면 무료 티어 AI로 대체 실험
- → 돈 벌기 시작한 뒤 켜도 늦지 않음. **STEP 1~2가 무료의 핵심.**

---

## STEP 4 — NO1의 PRO 기능을 "무료로" 자력 구현 (레벨업 후)

NO1이 월 ₩19,900 받는 **PRO 매크로(크림 자동입찰·최저가 경쟁·보관 매크로)**를, 우리는 **직접 만들어 구독료 0원**으로 쓴다.

### 어떻게 무료가 되나
- PRO 기능은 소프트웨어일 뿐 → **Electron(오픈소스, 무료)** 데스크톱 앱으로 자체 구현. 구독료가 나갈 곳이 없음
- 내 계정 자동화라 서버도 불필요(내 PC에서 구동) → 운영비 0

### 언제 시작하나 (초짜는 아직 X — 셋 다 충족 시)
1. STEP 1~2를 **2~4주 실사용**해서 소싱이 실제로 빨라졌다
2. 크림 **판매 리스팅이 상시 수십 건**이라 수기 리프라이싱이 번거로워졌다 (≈ 크림 레벨1 탈출, 월정산 200만+)
3. **계정 정지 리스크를 감수**하겠다는 판단 (⚠️ 크림 약관상 자동화 금지 — 초짜 계정 정지는 타격 큼)

### 만들 기능 (NO1 PRO 동일)
- [ ] 크림 자동 입찰 (개인/입점)
- [ ] 최저가 경쟁(리프라이싱) 자동화
- [ ] 보관 매크로
- [ ] 크림 & 솔드아웃 동시 입찰

> ⚠️ 원칙: **본인 계정·본인 리스크**로만. 탐지 회피/안티봇 우회 기능은 만들지 않는다(그건 별개의 잘못된 방향). 자동화 자체와 우회는 다른 문제.

## 비용 요약 — "언제까지 0원인가"

| 단계 | 월 비용 | 근거 |
|---|---|---|
| STEP 0 (NO1 무료 이용) | **0원** | NO1 무료 기능만 |
| STEP 1 (장부·입고·마진) | **0원** | Vercel+Supabase 무료 티어 |

→ **핵심 결론: STEP 1·2·4는 영구 무료로 운영 가능.** 유료 위험은 STEP 3(AI) 하나뿐이고 그마저 선택.
