## 벤치마크 실제 제품 (핵심 요약 — 06_BENCHMARK_ANALYSIS 참고)

- **제품명**: 넘버원 셀러센터(NANBA ONE) / 케이와이테크인. 영상은 이 제품의 **무료 웹 소싱툴** 홍보였음.
- **구성**: 데스크톱 매크로앱(Electron, 확인됨) + 데스크톱/웹 소싱툴 + Android OTP 자동입력앱.
- **가격**: 소싱툴·매크로 기본 = 무료 / **PRO ₩19,900/월 (연 ₩214,920)** = 크림 자동입찰·최저가 경쟁·보관 매크로.
- **수익 인사이트**: 데이터(시세·재고)는 무료로 다 주고, **시간을 아끼는 자동화(매크로)에서 과금**.

## 알아둘 리스크 (리서치 근거)

1. **웹 vs 데스크톱 분리**: 우리가 영상 보고 만들 웹툴(소싱·장부·입고)은 웹으로 충분하지만, **PRO 매출원인 자동입찰 매크로는 별도 Electron 데스크톱 앱**이 필요(브라우저 샌드박스 불가). 웹 MVP 먼저, 매크로는 별도 트랙.
2. **크림은 공식 API가 없고**, 자동 수집은 약관 위반 + 민사(DB권·부정경쟁) 리스크. 시세 기능 재현이 가장 큰 허들 — Phase 구조가 이 리스크를 뒤로 미루는 이유. (벤치마크 제품의 시세 수집 방식은 로그인 후 네트워크 분석으로 추가 확인 필요)
3. **매크로 = 계정 정지 리스크**: 크림 약관상 자동화 금지. 벤치마크 제품도 유저가 이 리스크를 감수하는 구조. 상용화 시 약관 고지 필수. 탐지 회피 기능은 만들지 않음.
4. **포이즌은 공식 오픈플랫폼이 있다** (open.poizon.com, 입점 상인 전제) — 합법적 자동화가 가능한 유일한 경로.
5. **무신사 등 구매내역은 공식 API가 없다** — 붙여넣기 파싱(Phase 1) → 이메일 파싱/브라우저 확장(Phase 2+)로 단계적 접근.
6. **iOS Safari는 네이티브 바코드 API가 없다** — zxing-wasm 포니필 필수 (04_PROJECT_SPEC 참고).
